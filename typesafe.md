# Typesafe AI Integration

If Typesafe AI is available, use it only where structured decision-making materially helps.

Useful cases:

- task classification/routing
- priority ranking
- bug classification
- risk assessment
- option selection
- deciding whether human review is needed
- acceptance classification

Typesafe AI is advisory.

Normal development must not depend on it.

Code reading, generation, editing, debugging, validation, testing, Git operations, and orchestration remain the responsibility of Codex and its subagents.

If Typesafe AI is unavailable or fails, continue normally.
